# 音の入れ方

このフォルダに音を置き、`manifest.json` に登録すると鳴るようになります。
**登録していないものは無音のまま**で、ゲームは何事もなく動きます
(全部そろえなくても、1つから順に足せます)。

## 手順

1. 音声ファイルをこのフォルダの下に置く
2. `manifest.example.json` を `manifest.json` にコピーする
3. 実際に置いたファイルの行だけ残して、他は消す(消した分は無音)
4. `npm run build` → デプロイ

## ファイルの仕様

| 用途 | 置き場所 | 長さの目安 | 備考 |
|---|---|---|---|
| BGM | `bgm/lobby.ogg` など | 1〜2分 | **繋ぎ目が自然につながるループ**にする |
| 効果音 | `sfx/hit.ogg` など | 0.1〜1秒 | 短く。長いと連打で重なって濁る |

- 形式は **OGG(Vorbis)** を推奨。MP3でも鳴りますが、同じ音質ならOGGのほうが小さくなります。
- **音量はファイル側で揃えてください。**ゲーム内の音量つまみは全体にかかるだけで、
  1つだけ大きい音を下げることはできません。
- BGMは通信量に直結します。**1曲1MB以内**を目安に(ビットレートを下げる/長さを詰める)。

## 場面と名前

BGMは4つです。

| 名前 | 場面 |
|---|---|
| `lobby` | 研究室・図鑑・ロビーなど、戦っていないとき |
| `battle` | 通常のステージ |
| `boss` | ボス戦(5の倍数のステージ) |
| `duel` | 決闘 |

効果音の名前は `manifest.example.json` を参照してください。

## 注意

- **著作権**: 公開しているゲームなので、必ず商用利用が許される音を使ってください。
  **クレジット表記が必要な素材を使う場合は、説明書に記載欄を追加します**ので伝えてください。
- ブラウザの制限で、**最初のクリックまでは音が鳴りません**。これは仕様です。
- 音量とミュートの設定は端末ごとに保存され、**引き継ぎコードでは移りません**
  (端末ごとの好みのため)。

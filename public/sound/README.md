# 音の入れ方

このフォルダに音を置き、`manifest.json` に登録すると鳴るようになります。
**登録していないものは無音のまま**で、ゲームは何事もなく動きます
(全部そろえなくても、1つから順に足せます)。

## 手順

1. 音声ファイルをこのフォルダの下に置く
2. `manifest.example.json` を `manifest.json` にコピーする
3. 実際に置いたファイルの行だけ残して、他は消す(消した分は無音)
4. `npm run build` → デプロイ

## ファイルの仕様

| 用途 | 置き場所 | 長さの目安 | 備考 |
|---|---|---|---|
| BGM | `bgm/lobby.mp3` など | 1〜2分 | **繋ぎ目が自然につながるループ**にする |
| 効果音 | `sfx/hit.mp3` など | 0.1〜1秒 | 短く。長いと連打で重なって濁る |

- 形式は **MP3** を推奨(どのブラウザでも鳴ります)。OGGでも鳴りますが、Safari で再生できないことがあります。
- **音量はファイル側で揃えてください。**ゲーム内の音量つまみは全体にかかるだけで、
  1つだけ大きい音を下げることはできません。
- BGMは通信量に直結します。**1曲1MB以内**を目安に(ビットレートを下げる/長さを詰める)。

## 場面と名前

BGMは4つです。

| 名前 | 場面 |
|---|---|
| `lobby` | 研究室・図鑑・ロビーなど、戦っていないとき |
| `battle` | 通常のステージ |
| `boss` | ボス戦(5の倍数のステージ) |
| `duel` | 決闘 |

効果音は**27種類**です。**`sfx/` に置いたファイル名(拡張子を除く)がそのまま名前**になります。
`hit.mp3` を置けば `hit` として鳴ります。

### 🔁 は「鳴らしっぱなし」の音

**🔁 が付いたものは、始まってから終わるまでループ再生されます。**
単発の音とは作り方が違います。**頭と尻が自然につながる短いループ**にしてください
(1〜2秒程度)。ブツッと切れる素材だと、繰り返しのたびに雑音になります。

### 研究室

| ファイル名 | 鳴る場面 | 長さ | 選ぶときの目安 |
|---|---|---|---|
| `select.mp3` | 素材庫のエレメントを調合台へ置いた | 0.1秒 | **極力控えめに**。何度も鳴る |
| `unselect.mp3` | 調合台から素材を戻した | 0.1秒 | `select` より低い音にすると分かりやすい |
| 🔁 `crafting.mp3` | 調合中(バーが進んでいる間) | 1〜2秒ループ | ぐつぐつ・回転するような持続音 |
| `craft.mp3` | 調合・強化に成功 | 0.8秒 | 完成した手応え |
| `craftFail.mp3` | 調合に失敗 | 0.6秒 | 失敗と分かる下降音 |
| 🔁 `gathering.mp3` | 採取中(バーが進んでいる間) | 1〜2秒ループ | 歩く・探る感じ |
| `gather.mp3` | 採取が終わってエレメント入手 | 0.5秒 | 拾う・きらめく音 |
| 🔁 `transmuting.mp3` | 錬成中(バーが進んでいる間) | 1〜2秒ループ | 変質していく持続音 |
| `transmute.mp3` | 錬成が終わった | 0.6秒 | 変化が完了した音 |
| `discover.mp3` | 新系統の発見・上位品質 | 1.2秒 | **一番豪華に**。滅多に鳴らない |

### 戦闘

| ファイル名 | 鳴る場面 | 長さ | 選ぶときの目安 |
|---|---|---|---|
| 🔁 `casting.mp3` | 自分が詠唱している間 | 1〜2秒ループ | 力を溜める持続音。**目立ちすぎない** |
| `cast.mp3` | 自分の詠唱が完了して発射 | 0.3秒 | 放つ音。鳴る回数が多いので短く |
| `enemyCast.mp3` | 敵の詠唱が完了して攻撃 | 0.3秒 | 自分の `cast` と**音色を変える**こと |
| `hit.mp3` | 自分の攻撃が敵に当たった | 0.2秒 | 最も回数が多い。**目立ちすぎない**打撃音 |
| `crit.mp3` | 会心の一撃 | 0.4秒 | `hit` より一段派手に |
| `damage.mp3` | 敵の攻撃が自分に当たった | 0.3秒 | `hit` と**はっきり区別**できる鈍い音 |
| `defeat.mp3` | 敵を撃破 | 0.5秒 | 崩れる・消滅する感じ |
| `heal.mp3` | 回復魔法 | 0.6秒 | 柔らかい上昇音 |
| `shield.mp3` | 護盾を張る | 0.5秒 | 硬い・張る感じ |
| `buff.mp3` | 闘気・瞑想・活力など強化 | 0.6秒 | 上向きの短いアルペジオ |
| `quake.mp3` | 地震系(全体攻撃) | 1.0秒 | 低く重い |
| `countdown.mp3` | 開始前の「3」「2」「1」 | 0.2秒 | 短い電子音。3回連続で鳴る |
| `start.mp3` | 「開戦」表示 | 0.8秒 | `countdown` より高く強い音 |
| `win.mp3` | 敵に勝った | 1.5秒 | 短いファンファーレ |
| `lose.mp3` | 敗退した | 1.5秒 | 沈む感じ |
| `escape.mp3` | 撤退した | 0.8秒 | 逃げる・離脱する感じ。`lose` とは別の音 |

### 共通

| ファイル名 | 鳴る場面 | 長さ | 選ぶときの目安 |
|---|---|---|---|
| `click.mp3` | タブの切り替え | 0.1秒 | **極力控えめに**。鳴りすぎると耳障り |

**`hit` `cast` `select` は鳴る回数が桁違いに多い**ので、この3つだけは特に短く・小さめの
音を選んでください。ここが合っていないと、他が良くても「うるさいゲーム」になります。

## 注意

- **著作権**: 公開しているゲームなので、必ず商用利用が許される音を使ってください。
  **クレジット表記が必要な素材を使う場合は、説明書に記載欄を追加します**ので伝えてください。
- ブラウザの制限で、**最初のクリックまでは音が鳴りません**。これは仕様です。
- 音量とミュートの設定は端末ごとに保存され、**引き継ぎコードでは移りません**
  (端末ごとの好みのため)。

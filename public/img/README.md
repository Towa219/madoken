# 画像素材の入れ方

このフォルダに画像を置き、`manifest.json` に登録すると、ゲームの見た目が
その画像に差し替わります。**登録していないものは今まで通り図形で描かれます**
(全部そろえなくても、1枚から順に差し替えられます)。

## 手順

1. PNG(背景透過)をこのフォルダの下に置く
2. `manifest.example.json` を `manifest.json` にコピーする
3. 使うファイルの行だけ残して、他は消す(消した分は図形のまま)
4. `npm run build` → デプロイ

## ファイルの仕様

| 用途 | 置き場所の例 | 推奨サイズ | 向き・基準 |
|---|---|---|---|
| プレイヤー | `player.png` | 高さ 200px 程度 | **正面〜右向き**・足元が画像の下端 |
| 敵(14形状) | `enemy/blob.png` など | 高さ 150〜250px | **左向き**(プレイヤーと向き合う)・足元が下端 |
| 弾(8属性) | `proj/fire.png` など | 64×64 程度 | **右向きに飛ぶ**絵・中心が画像の中心 |
| 戦闘背景 | `bg/field.png` | 960×540 | 地面のラインが下から80px付近 |

- 画像は**高さを基準に自動で拡大縮小**されます。元画像は大きめ(2倍程度)で用意すると、
  拡大時にぼやけません。
- 敵の形状名は14種類です:
  `blob` `imp` `golem` `wisp` `orb` `beast` `bird` `plant` `undead` `knight`
  `serpent` `insect` `eye` `fish`
- 属性名は8種類です:
  `fire` `water` `wind` `earth` `thunder` `ice` `light` `dark`

## 注意

- **著作権**: 公開しているゲームなので、必ず商用利用と再配布が許される素材を使ってください
  (CC0が最も安全です)。ライセンス表記が必要な素材を使う場合は、説明書に記載を追加します。
- 敵の色分け(`EnemyDef.color`)は図形描画用の設定です。画像を使う場合、色は画像側で表現します。
- 画像が読み込めなかったときは、その1枚だけ図形描画に戻ります(ゲームは止まりません)。
